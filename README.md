## 🌟 மறுவடிவமைக்கப்பட்ட முகப்புப் பக்கத்தின் ஓட்டம் (Editorial Redesign Flow)

1. **சினிமாட்டிக் ஹீரோ (Cinematic Edge-to-Edge Hero):**
   - முழுத்திரை ஒளிப்படப் பின்னணி + அடர் பச்சை எடிட்டோரியல் கிரேடியன்ட்
   - மூன்று வரிக் கம்பீரத் தலைப்பு:
     *உங்கள் கனவுகள்.*
     *உங்கள் முயற்சி.*
     *உங்கள் வளர்ச்சி.*
   - கோல்டு பார்டருடன் கூடிய வாட்ஸ்அப் உடனடி ஆலோசனை பொத்தான்
2. **அமைதியான எடிட்டோரியல் அறிமுகம் (A Quiet, Editorial Introduction):**
   - "ஒரு பெண்ணின் வளர்ச்சி, பல கனவுகளின் தொடக்கம்"
   - கோல்டு கோட்டுடன் கூடிய லட்சிய மேற்கோள் (Pull-Quote)
   - பெண் தொழில்முனைவோரின் அதிகாரப்பூர்வ போர்ட்ரெய்ட் படம்
3. **மகளிர் கடன் வாய்ப்புகள் (Asymmetrical Editorial Loan Panels):**
   - `01 · கூட்டுப் பொறுப்பு` — சுயஉதவிக் குழுக்கள்
   - `02 · விரிவாக்கம்` — சிறு தொழில் வளர்ச்சி
   - `03 · புதிய தொடக்கம்` — சுயதொழில் தொடக்கம்
   - நேரடி வாட்ஸ்அப் இணைப்புகள்
4. **முழுத்திரை ஒளிப்பட இடைவேளை (Full-Width Photographic Interlude):**
   - "தன்னம்பிக்கையுடன் தொடங்குங்கள். வளர்ச்சிக்கான வழியை அறிந்துகொள்ளுங்கள்."
5. **வழிகாட்டல் நெறிமுறை (Spacious 4-Step Hairline Timeline):**
   - மெல்லிய கோடுகளால் இணைக்கப்பட்ட `01, 02, 03, 04` படிகள்
6. **சேவை நெறிகள் (Why Choose Us - Refined Cards):**
   - தமிழில் எளிய விளக்கம், தேவைக்கேற்ற வழிகாட்டுதல், வெளிப்படைத்தன்மை
7. **அடிக்கடி கேட்கப்படும் கேள்விகள் (FAQs):**
   - அணுகல்தன்மை கொண்ட அக்கார்டியன்
8. **நேரடி உரையாடல் (Direct Conversation & Final CTA):**
   - "உங்கள் அடுத்த முயற்சியைப் பற்றி பேசுவோம்" — வாட்ஸ்அப் & நேரடி அழைப்பு
9. **எடிட்டோரியல் அடிக்குறிப்பு (Footer):**
   - ஸ்ரீ சின்னம், வழிசெலுத்தல், நிதிசார் மறுப்புரை

## 🛠️ இயக்குதல் மற்றும் சோதனை (Setup & Run)

```bash
# டெவலப்மென்ட் சர்வர்
npm run dev

# தயாரிப்பு உருவாக்கம் (Build & Typecheck)
npm run build

# தயாரிப்பு சேவையகம் தொடங்குதல்
npm run start
```
